# 小节页模板与实现

版本：2.4

| 文件 | 是什么 |
|---|---|
| `web/learn.html` + `web/js/teaching-app.js` | **实际的教学页**。正文由 `packages/teaching-content` 的数据渲染，题目由真实引擎判 |

| `web/css/task.css` | 做题页的分栏外壳 |

## 1. 页面骨架

```
topbar     目录开关 · 品牌 · 非官方徽标 │ 章节 + 小节标题 │ 进度 · 编辑器入口
learn
 ├ toc     课程目录：章可折叠，小节带进度点（未开始 / 进行中 / 已完成）
 └ reader
    ├ reader-scroll   小节正文（唯一的滚动容器）
    └ reader-foot     上一节 / 位置 / 下一节，三个固定槽
```

设计语言完全复用编辑器的 `css/styles.css`：颜色变量、`.btn`、`.badge`、`.switch-*`、`.origin-tag`、`.sev-*`、`.tk-*` 语法高亮色都是同一套，两个界面之间不会有割裂感。

## 2. 小节的推进结构

小节按段解锁，不是一次铺满一屏：

```
讲解（含规则 callout）
示例代码（行号 + 注释条 + 示例运行）
并排对照（自然语言 / 伪代码 / 真实语言，只有伪代码一栏着色）
─── 关卡 1：单选 ───────────────  答对才继续
   全部选项解析
   讲解
   反例（代码 + 它会报出的诊断）
─── 关卡 2：点击找错 ───────────  答对才继续
   逐行解析
   讲解
─── 关卡 3：填空 ──────────────  答对才继续
   全部候选解析
   小节伪代码题的**入口卡**（题面摘要 + 通过状态 + 「打开做题页」）
   章末大题入口
   参考解（锁定态）
```

题目本身不在课文里。课文里从头到尾只有阅读和关卡，**凡是要写代码的都去 `task.html`**——
原来题面和作答框上下排布，写一行就得往上翻一次题面看输入输出格式，
一道题下来要翻十几次。分开之后题面固定在左边，眼睛不用离开代码。

未解锁的段落**不渲染**（`.gated[hidden]`）。解锁时内容出现在文档末尾，上方一切保持不动。

## 4. 关卡的交互状态

| 状态 | 视觉 | 说明 |
|---|---|---|
| 未作答 | 反馈槽 `data-state="idle"`，「继续」disabled | 槽内是一句引导语 |
| 答错 | 该项 `.tried`（红底 + 降透明度，不可再点），反馈槽 `wrong` | 只说这一项为什么不对，然后可以再选 |
| 答对 | 该项 `.is-correct`（绿底 + 绿环），反馈槽 `right`，题 `.solved`，「继续」可用 | **此刻页面上没有任何元素移动或改变尺寸** |
| 已继续 | 「继续」变 disabled「已继续」 | 解析与后续内容出现在下方 |

填空题额外规则：填错的空标红并在约 0.9 秒后清空，候选词恢复可用；空的宽度按最长候选词写死，填入前后一致。

## 5. 判题结果的五种状态

`.verdict[data-state]` 取 `l0` / `l1` / `l2` / `l2r` / `pass`，面板尺寸恒定（730×314），内容在 `.verdict-scroll` 内滚动。层级条对学生显示为**语法 / 题目要求 / 运行结果 / 书写规范**，不出现内部编号。

| 状态 | 展示 |
|---|---|
| `l0` | 诊断列表 + 自动修复；不进入后面的判定 |
| `l1` | 哪条要求没满足、哪一行违规，各附理由 |
| `l2` | 通过数 + 失败情形的描述性提示（`caseHint`），**不含任何具体数据** |
| `l2r` | 同一题连续失败 3 次后，才给出期望 / 实际输出对比 |
| `pass` | 通过 + 书写规范建议（不影响判定）+ 参考解解锁 |

## 6. 两条硬性约束的落地方式

**布局稳定**（02 §3.5）——已实测：单选连续答错两次再答对、点击找错、填空填错重填、判题五状态切换、提示展开，全过程 `getBoundingClientRect` 的 x/y/width/height 与文档高度均无变化。

| 会变的东西 | 固定槽位 |
|---|---|
| 关卡反馈 | `.quiz-feedback` 高 66px，内部滚动 |
| 分级提示 | `.hint-row` 高 48px，`.hint-text` 内部滚动 |
| 判题结果 | `.verdict-scroll` 高 236px，内部滚动 |
| 「继续」说明 | `.gate-foot` 高 30px，`.gate-note` 单行省略 |
| 填空 | `.blank` 宽 104px |
| 目录进度点 | `.dot-state` 8×8，只换颜色 |
| 元素标注 | `.block::after` 绝对定位 + `opacity` |

**不写炫技文案 / 不编造学情**（02 §2.1、§3.4）——页面上没有引擎、CI、语法树、判题机制、内部规则 ID、尝试次数、易错点、应试话术。只保留两类：对学生有用的操作说明（三空格缩进、`<-` 自动转 `←`），以及规则来源标签（`CAIE 规定` / `编辑器约定`）。

## 6.2 课程主页

进入教学页先落在 `data-section="home"`：全部 23 章一次列出（AS 16 + A Level 7），已写好的那一章高亮并显示每个小节的进度条，其余标「尚未上线」。按钮文案随进度在「开始学习 / 继续 / 重看一遍」之间切换，槽位固定 88px，换词不会让整行抖。

- 进度存 `localStorage` 的 `caie.teaching.progress.v1`，键是 `章号/小节号`，**刷新不丢**。
- 「课程主页」是目录最上面的独立一项，不属于任何一章。
- 一节的关卡答完就算这一节完成；有题的小节要题目通过才算。**题目在 `task.html` 上做，通过时写的是同一份 `localStorage`**，所以回到课文时目录进度点、章节完成度、主页卡片都已经对上了。
- 课文页在 `pageshow` / `focus` / `visibilitychange` / `storage` 时重读一次进度——做题页改的是另一个文档里的 `localStorage`，不重读就还停在旧样子。
- 章末大题通过后，判题结果末尾给的是「回到课程主页 ›」，不再是没有下文的「本章到此为止」。

## 6.3 从课文跳进编辑器

示例代码上的「在实验室中打开」经 `localStorage` 交接（不是 `sessionStorage`——直接双击 HTML 打开时是 `file://`，两个页面的 session 互相看不见，交接会静默失败）。

带过去的文件**单独成组，放在用户自己的文件下面**，组标题可折叠：

```
Main.pseudocode          ✎ ✕
BubbleSort.pseudocode    ✎ ✕
───────────────────────────
› 课文文件            2   已归档 1
   Example_1_2_a.pseudocode   ↺ ⌄
```

| | 用户自己的文件 | 课文文件 |
|---|---|---|
| 位置 | 列表上半部分 | 下面的独立分组，可折叠 |
| 改名 | 可以 | 不可以（顶栏文件名只读） |
| 删除 | 可以 | 不可以 |
| 恢复原始 | — | `↺` 还原成课文里的那段代码 |
| 归档 | — | `⌄` 从列表里收起来；组标题出现「已归档 N」可以再翻出来，`↩` 取消归档 |

分组展开状态与「是否显示已归档」存在设置里。归档当前打开的文件会自动切到别的文件，并给一个可撤销的提示。同一段示例重复点击不会反复建文件，会切到已有那份并自动取消归档。

## 6.5 做题页 `task.html`

```
topbar     ‹ 返回课文 │ 章 · 题名 │ 通过状态（固定 76px 槽） · 编辑器入口
task-split
 ├ 左栏 .task-pane-left    题面：题干 / 输入输出 / 约束 / 示例 / 分级提示
 ├ .split-handle           拖动改左右宽度，存 caie.task.split.v1，最窄各 320px
 └ 右栏 .task-pane-right   作答：锁定骨架 / 带行号的编辑区 / 提交重置 / 判题面板 / 下一步
statusbar  层级 · 章节号 · 考纲映射 │ 进度与课文同步 │ 考纲版本
```

进入方式是课文里的入口卡，参数走查询串：`task.html?c=1&s=1.2&t=1.2.1`。找不到该题号时整页换成一条说明加一个回课文的按钮，不留半截界面。

三件和课文里那个内嵌作答框不同的事：

- **行号**。诊断按行号说话，作答区没有行号等于让学生自己数。锁定骨架也带行号，并且**和作答区连着数**（骨架 1–2，作答从 3 起）——提交上去的是两段拼起来的源码，诊断报的正是拼接后的行号。
- **草稿落盘**。作答内容存 `caie.teaching.answers.v1`（键 `章号/题号`），退回课文再进来接着写。编辑区右上角有固定宽度的「保存中 / 已保存」槽。
- **Tab 与缩进**。Tab / Shift+Tab / 行首退格都按三空格的停靠点走，和主编辑器一致，且全部经 `execCommand` 写入浏览器原生撤销栈（直接改 `value` 会把撤销栈清空）。

通过之后右栏末尾出现「回到这一节 / 下一节 ›」，顶栏状态槽换成「✓ 已通过」。

## 6.6 实际页面接了哪些引擎

```
teaching-content.js   内容数据（已去掉参考解）
language-engine.js    静态分析          → L0 语法层
language-adapter.js   中文诊断文案
exercise-engine.js    特征提取 / 比对 / 判题编排 → L1 / L2
runtime-engine.js     真实执行           → 跑每一组数据
runtime-messages.js   运行时错误的中文文案（与编辑器共用一份）
```

`web/js/teaching-app.js` 负责把内容渲染成 DOM、串起关卡解锁、画题目入口卡；`web/js/teaching-task.js` 负责题面、作答区、判题与进度，`web/js/task-page.js` 只把它摆成左右两栏。判题全部在浏览器里完成，不需要服务器。

**「在实验室中打开」**：示例代码经 `sessionStorage` 传给 `lab.html`，编辑器启动时把它建成 `FromLesson.pseudocode` 并直接打开。

**本地优先的一个已知限制**：判题用的输入与期望输出必须随页面下发，翻开开发者工具能看到。「用例对学生隐藏」这条约束管的是界面上不展示（[03-EXERCISE_SPEC.md](03-EXERCISE_SPEC.md) 4.3），不是保密。参考解不进浏览器包。

## 7. 版式参照页怎么用

`teaching-template.html` 与 `learn.html` 共用 `js/teaching-app.js`，区别只有一处：**参照页在加载渲染器之前，先用一份内联的占位数据覆盖 `window.CAIETeaching`**。

因此：

- 改版式只要改 `teaching-app.js` 或 `teaching.css`，两边同时生效，不存在「模板改了实际页没改」。
- 参照页里放的是**全部块类型**，包括实际章节暂时没用到的（Chapter 1 没有填空题，参照页有）。
- 想试一种新块：先在参照页的占位数据里加上、把形态定下来，再写进内容规格与真实章节。
- 参照页默认打开「元素标注」，每个块右上角浮出它在规格里的类型名。

参照页上题目同样只留入口卡；占位数据不在 `teaching-content.js` 里，所以点进去会落到做题页的「没有找到这道题」，这是预期——参照页要看的是入口卡的版式。
